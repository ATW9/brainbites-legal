Privacy Policy

Last updated: 17 November 2026

BrainBites is a personal automated video publishing tool operated by its owner. It uses the YouTube Data API and the TikTok Content Posting API solely to upload videos to the operator's own channels.

Data we access

Only the operator's own account credentials (OAuth tokens) and channel metadata. We do not collect, store or process any data about viewers or third parties.

Data sharing

None. Tokens are stored on a private server controlled by the operator and are never shared.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time via Google account permissions or TikTok app settings.

Contact

Contact the operator through the channel's about page.
